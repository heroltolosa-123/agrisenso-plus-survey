# Workshop deck — slide sources

The 21 slides of the enumerator training deck, one HTML file each, plus
`deck.json` which holds the order, sections and typefaces.

The deck itself renders at its Artifact URL, where it can be presented,
paged through and downloaded as a PDF. These are its sources, kept here
so they are backed up and editable.

To change a slide, edit its file and republish it to the deck. The
rendered PDF is not committed — it is a download of the live deck and
would be 8 MB of binary in every clone.
