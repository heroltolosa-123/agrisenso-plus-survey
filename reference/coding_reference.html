Enumerator and Respondent Coding

AGRISENSO Plus Baseline Study — reference card for the webapp survey (Instruments A and B)

Why codes at all. The identifier columns are the only link between an interview and the approved sample. Free text breaks that link: Hero Tolosa, H. Tolosa and HT are one person to you and three people to the dataset, and a case that cannot be matched back to the frame cannot be weighted, verified or re‑interviewed.

Where this applies. One screen only — Questionnaire Administration and Quality‑Control Information, the first screen of both instruments. Nothing on it is read aloud to the respondent. Fill it before you greet them, while you still have signal.

Three codes. Yours (EN‑RR‑NN), your supervisor's (SV‑RR‑N), and the respondent's, which is the Sampling Frame ID (I‑RR‑PPP‑NNNN). The Control Number is written by the app — never type it.

Enumerator code — EN-RR-NN

EN-02-07 — Dela Cruz, Juan M.

ENFixed. Always EN for an enumerator.
RRTwo‑digit region code of your home cluster — the region you were hired into, from the table below. It stays the same even on a week helping another cluster, so that the audit trail does not break on reassignment.
NNYour number inside that region, 01 upward, from the master roster. Assigned once, never reused — if you leave the study, your number is retired rather than given to your replacement.
— NameSpace, em dash, space, then Surname, First M. — surname first, comma, given name, middle initial with a full stop.
The separator matters. Code and name are stored in one column and split apart during analysis on that  — . Choose your entry from the pick‑list and it is always right. If you must type it, use the em dash the list uses — a hyphen, a slash or a double hyphen will not split.

Supervisor code — SV-RR-N

SV-02-1 — Santos, Maria L.

Same structure, one digit instead of two, because a region has a handful of supervisors rather than dozens of enumerators. Enter the officer who signs off your work, not whoever happens to be nearest. If your supervisor changes mid‑fieldwork, enter the one responsible for that day's work and tell both of them.

Respondent code — the Sampling Frame ID

A-02-ISA-0147

IA for a borrower, B for a comparison‑group respondent. A and B never share a code, even for the same household in the same barangay.
RRRegion code, from the table below.
PPPThree‑letter province abbreviation, from the key your cluster is issued with.
NNNNThe row number on the approved sampling frame, four digits, zero‑padded. This is what makes the code verifiable: it is a transcription, not an invention, and it reconciles one‑to‑one with the list.

Replacements

A replacement drawn from the reserve list keeps its own row number. Where your cluster's protocol tracks which case it replaced, append -R1 for the first replacement of that case, -R2 for the second: A-02-ISA-0147-R1. Never reuse the code of the case that dropped out, and never renumber the frame.

If the ID is not on the list, or is unreadable. Leave the field blank and flag the case for your supervisor the same day. Do not invent a number, do not guess the province abbreviation, and do not copy the ID from a neighbouring row. A blank flagged case is recoverable; a plausible wrong ID attaches this interview to someone else's record and is not.

Why there is no separate respondent number to compose

The app already holds two identifiers: this frame ID, which links the case to the sample, and the Control Number, which it writes itself and which is unique per interview. A third hand‑composed number would add nothing and would be the field most often typed wrong. So the frame ID is the respondent code — which is also why copying it exactly matters more than any other keystroke on that screen.

Province abbreviations (PPP)

Filled in by the study team for the sampled clusters only, and issued with your assignment sheet. Three letters, uppercase. Write your cluster's entries here on the first day of fieldwork so you are never abbreviating from memory:

Where a province already has an ID on the frame. If the approved list arrives with its own IDs printed on it — a LANDBANK account reference, for instance — those win. Copy them verbatim and ignore the structure above. The structure is for building a frame that has no IDs yet, not for rewriting one that has them.

Five ways this goes wrong

Do notBecause
Type your name without your codeThe roster column is split on the em dash; a bare name lands in the code position and the case is attributed to nobody.
Type over the Control NumberIt is the key that makes a retry on bad signal write one row instead of two.
Shorten or re‑spell the frame IDA-2-ISA-147 does not match A-02-ISA-0147. Zero‑padding is not decoration.
Use a colleague's code because you are covering their caseThe code records who was in the room. Enter your own, always.
Guess an ID to get past the screenBlank is accepted here and is recoverable. A wrong ID silently binds this interview to another respondent's record.
